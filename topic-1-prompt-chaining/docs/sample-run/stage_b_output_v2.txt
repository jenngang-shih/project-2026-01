這半年幾乎都用手機在玩，說真的，介面這件事比大家想的重要很多。像我常跑的那幾家，桌機版的排版和真人視訊清晰度都做得不錯，荷官畫面幾乎不會卡頓；但一換成手機版，尤其是舊一點的Android機型，載入真人視訊的等待時間明顯拉長，有時候轉場動畫還沒跑完，畫面就先卡住兩三秒，那種延遲在百家樂下注倒數的時候特別煩。滑動式選單的觸控反應也是，某幾個平台按鈕間距抓太密，常常手滑點錯桌。以我自己實際玩過的這幾家來說，整體體驗算是我用過裡面偏順的，但我也就摸過這幾家，不敢說是市面最好。選平台前建議自己先用免費試玩模式摸個幾分鐘再說，比看文案準。這邊也提醒一下，玩之前該有的心理準備還是要有——這終究是花錢的娛樂，別把介面順不順當成賺不賺的依據。
